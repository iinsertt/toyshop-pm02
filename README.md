# ToyShop — интернет-магазин игрушек

Консольное приложение интернет-магазина игрушек, разработанное в рамках
практического экзаменационного задания по дисциплине **ПМ.02 «Осуществление
интеграции программных модулей»** (вариант 5).

**Автор:** Подмарьков Роман Михайлович

## Описание

Система позволяет покупателю просматривать каталог игрушек (категории:
конструкторы, куклы, машинки, настольные игры), искать и фильтровать товары,
наполнять корзину и оформлять заказы. Администратор управляет товарами и
заказами через отдельную панель.

## Технологии

- **Python 3.10+** (разработано на 3.14)
- **JSON** — хранение каталога товаров
- **SQLite** (`sqlite3`) — хранение заказов
- **logging** — журналирование в файл
- **pytest** — модульные и интеграционные тесты
- **python-docx / matplotlib / reportlab** — генерация документации
- **Git** — контроль версий

## Установка

```bash
pip install -r requirements.txt
```

## Запуск программы

Из корневой папки проекта:

```bash
python src/main.py
```

> **Примечание для Windows:** программа автоматически переключает вывод на UTF-8
> для корректного отображения кириллицы и символа «₽». Рекомендуется запускать
> в терминале VS Code или Windows Terminal.

## Использование

После запуска доступно меню из четырёх разделов:

1. **Каталог товаров** — просмотр, поиск по названию, фильтрация по категории и цене.
2. **Корзина** — добавление товара по `id` (например, `pr_001`), изменение количества, удаление.
3. **Оформить заказ** — ввод данных покупателя, валидация, сохранение в базу данных.
4. **Админ-панель** — просмотр заказов, изменение статуса, управление товарами.

Журнал работы сохраняется в `logs/app.log`, база заказов — в `orders.db`.
